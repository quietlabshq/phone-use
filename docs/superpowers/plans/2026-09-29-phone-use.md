# phone-use Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, open-source MCP server that lets AI agents see and operate an iPhone. The initial implementation targets macOS and the iOS Simulator, with physical input supplied by Task 10. The end goal is independent physical-iPhone control from either macOS or Linux (Tasks 15-20). Android is a future extension only.

**Architecture:** A Swift package with one `Phone` protocol and two backends. `SimulatorPhone` uses `simctl` screenshots and AXe input. `HardwarePhone` uses AVFoundation capture of the USB iPhone and hands HID reports to an injected `HIDTransport`. A stdio MCP server exposes the tools, and a CLI exposes the same actions for manual testing.

**Tech Stack:** Swift 6 (swift-tools 6.1, macOS 14+), Swift Testing, `modelcontextprotocol/swift-sdk` 0.12.x, `apple/swift-argument-parser`, AVFoundation, CoreMediaIO, ImageIO.

**Spec:** `docs/superpowers/specs/2026-09-29-phone-use-design.md`. Read `research/learnings.md` first, because it has the verified simulator facts, AXe syntax, MCP SDK API, and environment gotchas.

## Global Constraints

- Local v1 (Tasks 1-12): no cloud or network calls. Optional remote access is planned in Tasks 13-14; local use never requires it. No telemetry in either mode.
- The initial macOS implementation uses public macOS APIs and the AXe CLI. Tasks 15-20 add Linux-specific adapters and explicitly evaluated capture protocols. The input transport and device management come from a separate module owned by another agent (Task 10).
- Never use the em dash character in code, docs, or commit messages.
- Conventional Commits. One logical change per commit. Commit on `main`, no branches.
- Tool coordinates are screenshot pixels. The long edge of a screenshot is at most 1344 px.
- Typing is US-ASCII only. Reject other characters with an error that names them.
- AXe must be >= 1.8.0. The path comes from env `PHONE_USE_AXE`, defaulting to `axe` on `PATH`. On this Mac, use `/tmp/axe18/axe` until Homebrew is fixed.
- Test simulator: iPhone 17, UDID `842C0EF9-652A-4285-8148-1324C6EA2C4D`, 1206x2622 px, 402x874 pt.

## Review Focus

- A tool call with coordinates outside the screenshot: return an MCP error result (`isError: true`) with the valid range, never crash or clamp silently. Owner: Task 7, `ToolDispatcher` test `outOfBoundsTapIsError`.
- Two agents acting on one phone at the same time: actions must run one after another, never interleaved. Owner: Task 7, test `actionsOnOnePhoneAreSerialized`.
- `type_text` with emoji or accented letters: error names the bad characters and types nothing. Owner: Task 2, test `rejectsNonASCIIWithoutPartialInput`.
- AXe missing or too old, or no simulator booted: `list_phones` returns an empty list plus a readable hint, not a crash. Owner: Task 5, test `missingAxeGivesHint`.
- Input transport missing or iPhone not connected to it: hardware actions fail fast with "input device not connected", and screenshots still work. Owner: Task 9, test `actionFailsFastWhenHostDisconnected`.

public struct PixelPoint: Hashable, Sendable, Codable { public var x: Int; public var y: Int }
public struct PixelSize: Hashable, Sendable, Codable { public var width: Int; public var height: Int }

public struct ScreenshotScaler: Sendable {
    public let native: PixelSize
    public let scaled: PixelSize
    public init(native: PixelSize, maxLongEdge: Int = 1344)

    public func toNative(_ p: PixelPoint) throws -> PixelPoint
}

public enum Modifier: String, Sendable, Codable, CaseIterable { case control, shift, option, command }
public enum Key: Hashable, Sendable {
    case enter, escape, backspace, tab, space, up, down, left, right
    case letter(Character)            // a-z, used for shortcuts like Cmd+H
    public init?(name: String)        // "enter", "escape", "backspace", "tab", "space",
                                      // "arrow_up" ..., or a single letter "a"-"z"
}
public enum PhoneAction: Sendable, Equatable {
    case home
    case tap(PixelPoint, count: Int)                       // count 1...3
    case longPress(PixelPoint, milliseconds: Int)
    case swipe(from: PixelPoint, to: PixelPoint, milliseconds: Int)
    case typeText(String)
    case key(Key, modifiers: [Modifier], repeat: Int)

public enum PhoneKind: String, Sendable, Codable { case simulator, hardware }
public struct PhoneInfo: Sendable, Codable, Equatable {
    public let id: String; public let name: String; public let kind: PhoneKind
    public let screenSize: PixelSize     // native pixels
}
public enum PhoneError: Error, Equatable, CustomStringConvertible {
    case outOfBounds(PixelPoint, PixelSize)
    case unsupportedCharacters(String)
    case inputNotConnected(String)
    case toolUnavailable(String)
    case commandFailed(String)
    case phoneNotFound(String)
}
public protocol Phone: Sendable {
    var info: PhoneInfo { get }
    func screenshot() async throws -> CGImage
    func perform(_ action: PhoneAction) async throws
}
public protocol PhoneRegistry: Sendable {

    func discover() async -> (phones: [any Phone], hints: [String])
}
public protocol Sleeper: Sendable { func sleep(milliseconds: Int) async throws }
public struct RealSleeper: Sleeper { public init() {} }  // Task.sleep

}
public struct KeyboardReport: Equatable, Sendable {
    public var modifiers: UInt8; public var keys: [UInt8]    // up to 6
    public static let empty = KeyboardReport(modifiers: 0, keys: [])
    public var payload: [UInt8]                               // 8 bytes, keys zero-padded
}
public struct MouseReport: Equatable, Sendable {
    public var buttons: UInt8; public var dx: Int8; public var dy: Int8; public var wheel: Int8

}
public struct ConsumerReport: Equatable, Sendable { public var usage: UInt16; public var payload: [UInt8] } // 2 bytes LE
public enum HIDReport: Equatable, Sendable {
    case keyboard(KeyboardReport), mouse(MouseReport), consumer(ConsumerReport)
    public var id: ReportID
    public var payload: [UInt8]
}
public protocol HIDTransport: Sendable {
    func send(_ report: HIDReport) async throws
    func isHostConnected() async -> Bool
}

### Task 5: Simulator backend

**Files:** `Sources/PhoneUseSimulator/{SimulatorPhone,SimulatorRegistry}.swift`, `Tests/PhoneUseSimulatorTests/{SimulatorPhoneTests,SimulatorIntegrationTests}.swift`

**Interfaces:**

```swift
public actor SimulatorPhone: Phone {
    public nonisolated let info: PhoneInfo
    public let pointScale: Double            // native pixels per point, e.g. 3.0
    public init(udid: String, name: String, screenSize: PixelSize, pointScale: Double,
                axe: String, runner: any ProcessRunner)
}

    public init(axe: String = ProcessInfo.processInfo.environment["PHONE_USE_AXE"] ?? "axe",
                runner: any ProcessRunner = LiveProcessRunner())
}
```

Behavior:
- `discover()` runs `xcrun simctl list devices booted -j` and keeps devices whose name starts with "iPhone". For each one:
  - Take a screenshot to get `screenSize`.
  - Run `axe describe-ui --udid U` and read the root `frame.width` to get `pointScale = screenSize.width / frameWidth`.
  - Check `axe --version` once. If it fails or is < 1.8.0, return no phones and the hint `"AXe >= 1.8.0 is required (set PHONE_USE_AXE)"`.
  - If none are booted, return the hint `"No booted iPhone simulator. Boot one with: xcrun simctl boot <udid>"`.
- `screenshot()`: `xcrun simctl io U screenshot --type=png <tmpfile>`, then load it and delete the file.
- Converting pixels to points: `Double(px) / pointScale`, formatted with up to 2 decimals.

| Action | AXe command |
|---|---|
| `tap(p, 1)` | `axe tap -x X -y Y --udid U` |
| `tap(p, n>1)` | `axe batch --udid U --step "tap -x X -y Y" --step "sleep 0.08"` (repeated n times, last sleep dropped) |
| `longPress(p, ms)` | `axe touch -x X -y Y --down --up --delay S --udid U` |
| `swipe(a, b, ms)` | `axe swipe --start-x .. --start-y .. --end-x .. --end-y .. --duration S --udid U` |
| `typeText(t)` | Validate with `KeyboardMap.strokes`, then `axe type --stdin --udid U`, with t passed as stdin |
| `key(k, [], r)` | `axe key <usage> --udid U`, run r times |
| `key(k, mods, r)` | `axe key-combo --modifiers 227,225 --key <usage> --udid U`, run r times |

- Non-zero exit throws `PhoneError.commandFailed(stderr)`.

    public var stepCounts: Int = 8; public var stepIntervalMs: Int = 8
}
public struct TimedReport: Equatable, Sendable { public let report: HIDReport; public let delayAfterMs: Int }

public enum PointerPlanner {
    /// 40 reports of (-127, -127): pins the pointer to the top-left corner at any gain.
    public static func resetToCorner() -> [TimedReport]
    /// Moves from the corner to `to`. dx counts = round(x / pixelsPerCountX), sent as steps of
    /// stepCounts with the remainder last, same for y (both axes interleaved in the same reports).
    public static func move(to: PixelPoint, gains: PointerGains) -> [TimedReport]
    public static func tap(_ p: PixelPoint, count: Int, gains: PointerGains) -> [TimedReport]
        // reset + move + count x (down 60ms, up 80ms)
    public static func longPress(_ p: PixelPoint, ms: Int, gains: PointerGains) -> [TimedReport]
    public static func swipe(from: PixelPoint, to: PixelPoint, ms: Int, gains: PointerGains) -> [TimedReport]
        // reset, move to `from`, button down, spread the move steps evenly over `ms`, button up
}
public enum KeyboardDriver {
    public static func type(_ text: String, keyIntervalMs: Int = 12) throws -> [TimedReport]
        // press + release per character
    public static func key(_ k: Key, modifiers: [Modifier], repeat: Int, keyIntervalMs: Int = 12) -> [TimedReport]

public enum CursorLocator {

    /// threshold, largest first, dropping blobs smaller than minPixels.

    public static func grayscale(_ image: CGImage) -> [UInt8]
}
public enum PointerCalibration {
    /// Reset, move to (300, 600) counts-space start, capture A; move +200 counts in x, capture B;
    /// the rightmost blob of changedBlobs(A, B) minus the leftmost gives pixels for 200 counts.
    /// Same for y. Repeats 3 times and averages. Throws commandFailed("cursor not visible in capture")
    /// if fewer than 2 blobs appear.

                           base: PointerGains) async throws -> PointerGains
